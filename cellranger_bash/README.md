# Cell Ranger bash scripts

This folder contains representative SLURM batch scripts used for Cell Ranger preprocessing on the BlueBEAR HPC system.

The uploaded script is provided as an example template; similar scripts were used for preprocessing all fetal brain samples and regions with sample-specific FASTQ directories and output identifiers.
